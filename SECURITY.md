# Security Policy

## Reporting a vulnerability

Email **support@discolike.com** with a description of the issue, steps to
reproduce, and the affected package/version. Please do not open a public
GitHub issue for security reports.

We aim to acknowledge reports within 3 business days.

## Supported versions

Only the latest released versions of `discolike` and `discolike-cli` on PyPI
receive security fixes.

## Scope

This repository covers the Python SDK and CLI. Vulnerabilities in the
DiscoLike API or platform itself should also go to support@discolike.com.
